# Lover & Law 📜✨

> "Long story short, I survived... finals week."

**Lover & Law** is a scalable, multi-tenant Knowledge Hub and AI-driven study planner designed for students who want to romanticize their academic life while staying ruthlessly organized.

Built with **React**, **Tailwind CSS**, and **Google Gemini AI**, it combines aesthetic pleasure with powerful productivity tools.

## 🌟 Features

### 🧠 AI Intelligence (Gemini Powered)
- **Document Analysis:** Upload PDFs or notes (Local Storage) and get instant executive summaries and tags.
- **Proactive Executive Planner:** The system detects when you are falling behind (e.g., Exam in 3 days + 10 unread documents) and generates a rescue study plan.
- **Exam Prep Center:** Generate **Cheat Sheets** and **Mock Quizzes** instantly based on subject topics.
- **Note Refinement:** Polish your rough notes into structured, academic summaries.

### 📅 Smart Scheduling
- **Visual Calendar:** Track Classes, Exams, and Study Blocks.
- **Event Management:** Add, **Edit**, and Delete events directly from the dashboard or calendar view.
- **Exam Countdown:** Always know how many days are left until D-Day.

### 🎨 Eras Theming
Switch between immersive themes based on your mood:
- 💖 **Lover:** Pink, dreamy, and optimistic.
- 🐍 **Reputation:** Dark, edgy, and focused.
- 🕰️ **Midnights:** Deep indigo, late-night study vibes.
- 🍂 **Evermore:** Earthy, cottage-core, and stoic.

### 📚 Knowledge Management
- **Subject Dashboard:** Dedicated space for every course.
- **Literature Tracker:** Manage reading lists and get AI summaries of recommended books.
- **File Roster:** Organize uploads by subject.

## 🚀 Getting Started

### Prerequisites
- Node.js installed.
- A **Google Gemini API Key** (Get it free at [Google AI Studio](https://aistudio.google.com/)).

### Installation

1. **Install Dependencies:**
   ```bash
   npm install react react-dom framer-motion lucide-react @google/genai date-fns jspdf
   ```

2. **Run the Application:**
   ```bash
   npm start
   ```

### ⚙️ Configuration

1. Open the application.
2. Click the **Settings (Gear Icon)** in the top right corner.
3. Paste your **Gemini API Key** in the configuration panel.
4. Save and reload.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript
- **Styling:** Tailwind CSS (with custom glassmorphism effects)
- **AI:** Google GenAI SDK (`@google/genai`)
- **Icons:** Lucide React
- **Animations:** Framer Motion
